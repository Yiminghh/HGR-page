# Institution logo sources

These assets are used only in the local HGR visual prototype. Keep the original
colors and proportions, and confirm each institution's brand-use requirements
before public launch.

- `imperial-wordmark.svg`: converted from Imperial's current official `IMPERIAL`
  wordmark in `HGR-latex/CoverLetter/Images/ICL_Logo_Blue_RGB.pdf`
- `qmul-no-year.png`: cropped from Queen Mary's official horizontal lockup to
  retain the crest and university name without the separate `Est. 1785` mark
- `stanford.png`: `https://www.stanford.edu/icon4.png`
- `yonsei-light.png`: `https://www.yonsei.ac.kr/sites/en_sc/images/common/header_logo2.png`
